Артефакт этапа 3: Двумерный анализ (EDA)

🎯 Цель этапа

Понять связи в данных:

признак ↔ целевая переменная (SalePrice) — какие признаки важны для цены;
признак ↔ признак — есть ли дубликаты (мультиколлинеарность).
Данные: data/train_clean.csv, data/test_clean.csv (результат этапа 1).
Целевая переменная: SalePrice.
Ожидаемый размер: train ~1460 строк, ~80 столбцов.

📚 Что практикуем

DataFrame.corr() — корреляция Пирсона;
sns.scatterplot — форма связи;
sns.boxplot — распределение цены по категориям;
groupby().agg() — сводки по категориям;
sns.heatmap — визуализация матрицы корреляций;
where + stack + reset_index — поиск пар с высокой корреляцией.
🛠 Задачи этапа

3.1. Корреляции с целевой переменной

Что делаем: считаем корреляцию Пирсона SalePrice с каждым числовым признаком, сортируем по убыванию. Смотрим топ-15 положительных и топ-10 отрицательных.

Зачем: понять, какие признаки важны для цены (сильные — в модель, слабые — кандидаты на удаление) и в каком направлении они влияют.

На что смотрим в выводе:

какие признаки в топе (ожидаемо: качество, площадь, гараж, возраст);
какие в «хвосте» — кандидаты на удаление;
есть ли странные знаки (например, отрицательная корреляция у признака, который «должен» быть положительным) — повод для scatter plot.
3.2. Heatmap корреляций топ-признаков

Что делаем: берём 15 признаков с наибольшей корреляцией с SalePrice, строим матрицу корреляций 15×15 и рисуем тепловую карту.

Зачем: проверить мультиколлинеарность — не дублируют ли сильные предикторы цены друг друга.

На что смотрим:

ярко-красные ячейки вне диагонали → |r| > 0.8 → пара-дубликат;
пары с |r| > 0.8 — кандидаты на удаление одного из двух;
диагональ всегда 1.00 — игнорируем.
3.3. Scatter plots: ключевые числовые vs SalePrice

Что делаем: строим 3 точечных графика для сильнейших признаков (по результатам 3.1) против SalePrice.

Зачем: увидеть форму связи — линейная, ступенчатая, с выбросами. Пирсон ловит только линейную, поэтому scatter обязателен.

На что смотрим:

форма: прямая линия / ступеньки / кривая / «облако»;
выбросы — точки далеко от основной массы;
гетероскедастичность — разброс растёт с X.
3.4. Boxplots: категориальные vs SalePrice

Что делаем: строим 4 boxplot (сетка 2×2) для ключевых категориальных / псевдочисловых признаков против SalePrice.

Кандидаты:

OverallQual — оценка качества (1–10), фактически порядковая;
Neighborhood — район (25 категорий);
GarageCars — число мест в гараже (0–4);
CentralAir — кондиционер (Y/N).
Зачем: увидеть, как цены различаются по категориям — какие категории дороже, какие дешевле, насколько сильный разброс.

На что смотрим:

медиана по категориям — где рост, где падение;
разброс (высота «ящика») — насколько цены стабильны внутри категории;
выбросы (кружки) — аномально дорогие/дешёвые дома.
3.5. Агрегации по категориям

Что делаем: группируем по Neighborhood и считаем count, mean, median, std по SalePrice. Сортируем по медиане — от дорогих к дешёвым.

Зачем: получить числовые сводки — не только «на глаз» с boxplot, но и конкретные медианы/средние по районам. Найти топ дорогих и топ дешёвых районов.

На что смотрим:

count — если < 5, статистика ненадёжна (маленькая выборка);
median vs mean — если сильно расходятся, есть выбросы;
std — разброс внутри района;
разница между самым дорогим и самым дешёвым.
3.6. Поиск мультиколлинеарности

Что делаем: строим полную матрицу корреляций по всем числовым признакам. Оставляем только верхний треугольник (без дублей A↔B/B↔A и диагонали). «Расплющиваем» в длинный список пар. Фильтруем |r| > 0.8.

Зачем: найти все пары-дубликаты, а не только среди топ-15. Heatmap показывает 15×15, а здесь — вся матрица (~30×30).

На что смотрим:

список пар с |r| > 0.8;
для каждой пары — решаем, какой признак оставить (проще интерпретируется / сильнее с целевой).
❓ Вопросы для самопроверки

Топ-3 признака с наибольшей корреляцией с SalePrice?
Есть ли пары признаков с корреляцией > 0.8 между собой (мультиколлинеарность)?
Самый дорогой и самый дешёвый Neighborhood по медиане?
Все ли дома с CentralAir='N' дешёвые?
Форма связи у топ-3 признаков — линейная / ступенчатая / с выбросами?
Есть ли выбросы на scatter plot, которые стоит проверить на этапе 4?
⚠️ Ловушки, о которых помним

Пирсон ловит только линейную связь. r ≈ 0 ≠ «связи нет». Парабола даёт r ≈ 0, хотя связь идеальная.
Корреляция ≠ причинность. OverallQual = 0.79 — не доказывает, что качество вызывает цену. Возможен третий фактор.
Выбросы искажают r. Один экстремальный дом может «сдвинуть» корреляцию.
Маленькие категории (count < 5) — статистика ненадёжна.
Мультиколлинеарность — проблема только для линейных моделей; деревья справляются.
NaN игнорируются в corr() попарно — знаменатель у разных пар может отличаться.
